# Csharp13Net Feature Demos

This project demonstrates new features and improvements in C# 13 and .NET 9. Each feature is implemented as a separate example and can be executed from the console application.

## Features Covered

1. **New Lock Object**
2. **Task.WhenEach**
3. **Params Collections**
4. **Semi-Auto Properties**
5. **Hybrid Cache**
6. **Built-in OpenAPI Document Generation** *(commented out)*
7. **SearchValues Improvements**
8. **New LINQ Methods**
9. **Built-in UUID v7 Generation**
10. **Implicit Index Access**
11. **Partial Properties**
12. **Allows ref struct**

## How to Run

1. Build the project using Visual Studio or `dotnet build`.
2. Run the application.
3. Enter the option number for the feature you want to execute.

## Requirements

- .NET 9 SDK
- C# 13

## Usage Example


You will be prompted to enter an option number. Enter a number between 1 and 12 to see the corresponding feature demo.

## Project Structure

- `Program.cs`: Main entry point and feature selector.
- `Features/`: Contains individual feature demo implementations.
